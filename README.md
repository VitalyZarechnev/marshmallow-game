# Marshmallow Platformer 3D

3D-платформер, в котором зефирка прыгает по островам-лабиринту над водой, чтобы добраться до кружки кофе.

## Геймплей

- Зефирка перемещается по островам, сгенерированным в виде лабиринта (15x15 сетка)
- Цель: добраться до кружки кофе на самом дальнем острове
- 3 жизни (зависит от сложности). Потеря жизни при падении в воду или взрыве моба
- Мобы (Minecraft-стиль) патрулируют острова и взрываются при контакте
- Песочные острова тонут когда зефирка стоит на них
- Модификаторы: сердца (доп. жизнь), щит (блокирует урон), ускорение прыжка
- При потере жизни/рестарте все острова и мобы восстанавливаются

## Управление

### Desktop
- **WASD / Стрелки** — движение
- **Пробел** — прыжок
- **ПКМ + drag** — вращение камеры

### Mobile
- **Джойстик** (левый нижний угол) — движение
- **Кнопка JUMP** (правый нижний угол) — прыжок
- **Touch drag** (правая половина экрана) — вращение камеры

## Уровни сложности

| Параметр | Лёгкий | Средний | Сложный |
|---|---|---|---|
| Жизни | 5 | 3 | 1 |
| Шанс моба | 15% | 25% | 35% |
| Песочные острова | 5% | 10% | 18% |
| Скорость погружения | медленная | средняя | быстрая |

## Скины

4 скина зефирки: Базовый, Очки, Ковбой, Ангел.

## Статистика

Игра собирает и хранит в localStorage:
- Прыжки, смерти (от взрыва/утопления), затопленные острова, победы
- Игры по скинам и по уровням сложности
- Собранные модификаторы (сердца, щиты, ускорение прыжка)

Просмотр: кнопка «Статистика» в главном меню или на паузе.

## Архитектура: Atomic Design

Проект организован по методологии Atomic Design, адаптированной для 3D-игры на React Three Fiber.

### Структура проекта

```
src/
├── main.tsx                          # Точка входа
├── App.tsx                           # Root: Canvas + KeyboardControls + Providers
│
├── config/
│   ├── constants.ts                  # Общие константы (WATER_Y, ISLAND_HEIGHT, сетка)
│   └── difficulty.ts                 # Пресеты сложности (easy/medium/hard)
│
├── stores/
│   ├── GameStore.ts                  # MobX стор (позиция, жизни, состояние игры)
│   └── StatsStore.ts                 # Статистика (localStorage)
│
├── utils/
│   ├── textures.ts                   # Процедурные текстуры (трава, земля, песок, горы)
│   ├── islandGeometry.ts             # Геометрия островов (box + top plane с UV-тайлингом)
│   └── levelGenerator.ts             # Генерация лабиринта (DFS + BFS)
│
├── components/
│   ├── atoms/                        # Минимальные визуальные единицы
│   │   ├── Lighting.tsx              # HemisphereLight + DirectionalLight (следует за игроком)
│   │   ├── LandingIndicator.tsx      # Круг-индикатор приземления
│   │   ├── MarshmallowBody.tsx       # Геометрия зефирки + GPU fire shader
│   │   ├── MarshmallowFace.tsx       # Лицо (глаза, улыбка, удивление, румянец)
│   │   ├── CoffeeMug.tsx             # Кружка кофе (цель)
│   │   └── JumpButton.tsx            # Кнопка прыжка (мобильная)
│   │
│   ├── molecules/                    # Составные компоненты с локальным состоянием
│   │   ├── Joystick.tsx              # Аналоговый джойстик
│   │   ├── SandIsland.tsx            # Тонущий песочный остров с GPU-частицами
│   │   ├── Modifier.tsx              # Модификаторы (сердце, щит, ускорение)
│   │   └── HUD.tsx                   # Отображение жизней и модификаторов
│   │
│   ├── organisms/                    # Сложные компоненты с игровой логикой
│   │   ├── Player.tsx                # Зефирка: движение, прыжки, утопление, горение
│   │   ├── Mob.tsx                   # Моб: патруль, взрыв (merged geometry + vertex colors)
│   │   ├── GrassIslands.tsx          # Merged grass islands (1 draw call) + коллайдеры
│   │   ├── Floor.tsx                 # Вода (GLSL shader) + морское дно
│   │   ├── Mountains.tsx             # Бесшовная горная панорама (цилиндр)
│   │   ├── FollowCamera.tsx          # Камера: слежение, intro-анимация, вращение
│   │   ├── TouchControls.tsx         # Мобильные контролы (Joystick + JumpButton)
│   │   └── GameOverScreen.tsx        # Экран победы/поражения
│   │
│   └── templates/
│       ├── GameScene.tsx             # 3D-сцена (Physics, Sky, Fog)
│       └── MainMenu.tsx              # Главное меню (скины, сложность, статистика)
```

### Уровни Atomic Design

| Уровень | Описание | Примеры |
|---|---|---|
| **Atoms** | Чистая геометрия, без игровой логики | MarshmallowBody, CoffeeMug, Lighting |
| **Molecules** | Группы атомов с локальным состоянием | SandIsland, Modifier, Joystick |
| **Organisms** | Полноценные игровые сущности с AI/логикой | Player, Mob, Floor |
| **Templates** | Компоновка сцены | GameScene, MainMenu |

### Потоки данных

```
GameStore (MobX)
  ├── Player читает/пишет: position, lives, isGrounded, isBurning
  ├── Mob читает: position → определяет игрок на острове
  ├── GrassIslands читает: resetEpoch → сброс островов
  ├── FollowCamera читает: position, cameraYaw
  └── HUD/GameOverScreen наблюдают: lives, isGameOver, isWin

StatsStore (MobX + localStorage)
  ├── Player записывает: прыжки, смерти
  ├── Modifier записывает: собранные модификаторы
  ├── App записывает: игры по скинам/сложности
  └── MainMenu/PauseOverlay отображают статистику

touchInput (глобальный объект, не React state)
  ├── Joystick пишет: forward, right, jump
  ├── Player читает в useFrame
  └── FollowCamera читает в useFrame
```

## Генерация уровня

1. **DFS лабиринт** — рекурсивный обход создает связную сетку 15x15
2. **BFS путь** — гарантирует достижимость цели от спавна
3. **35% пропуск** — не-критичные острова случайно удаляются (создают пустоты)
4. **Случайный сдвиг** — каждый остров смещен до +-25% от позиции в сетке
5. **Высотная карта** — острова растут по высоте с удалением от спавна (0..16)
6. **Мобы** — шанс зависит от сложности (15-35%)
7. **Песочные острова** — шанс зависит от сложности (5-18%)
8. **Модификаторы** — сердца, щиты, ускорение прыжка на случайных островах

## Графика и оптимизации

### Рендеринг
- **Вода**: Custom GLSL ShaderMaterial — волны (vertex displacement), fresnel, specular, пена
- **Морское дно**: GLSL shader — FBM noise, каустика, песок/камни
- **Текстуры**: Процедурные Canvas-текстуры (пиксельный стиль Minecraft)
- **Горы**: Canvas 4096x1024, 7 слоев с атмосферной перспективой и снежными шапками
- **Небо**: @react-three/drei Sky (атмосферное рассеивание Прееттхэма)
- **Огонь**: GPU fragment shader (FBM noise на цилиндре, бесшовный)
- **Частицы**: InstancedBufferGeometry для песка, взрывов мобов
- **Туман**: Линейный fog скрывает края карты

### Оптимизации (draw calls: ~1500 → ~65)
- Все травяные острова merged в 2 меша (box + top plane) — **2 draw calls**
- Каждый моб: 13 мешей merged в 1 с vertex colors + vertex shader leg animation
- Песочные острова: кешированные текстуры на уровне модуля
- Тени: shadow camera следует за игроком, уменьшен shadow map
- Вода/дно: сниженные subdivisions (64×64 / 48×48)
